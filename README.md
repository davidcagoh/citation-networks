# Citation Networks

Public shell for citation-network research by David Goh.

The active literature-research system is [Literature Workbench](https://github.com/davidcagoh/literature-workbench), a local-first tool for evidence-grounded literature discovery, review planning, synthesis, and verification. Its predecessor history is retained in this repository’s Git history and in the Workbench repository.

[Zeitgeist](https://github.com/davidcagoh/zeitgeist) is a separate private research program focused on temporal and community structure in citation networks.

This repository is intentionally kept small: it provides public project identity and historical provenance, while active implementation lives in the dedicated repositories above.
